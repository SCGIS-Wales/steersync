# Team knowledge base

This repository has a knowledge base named `team-knowledge`, indexed from `{knowledge_folder}/`.

- Before answering questions about the platform, runbooks, CVEs or past incidents, search it
  with the `knowledge` tool.
- For exact identifiers (CVE numbers, ticket keys, resource ids), also grep `{knowledge_folder}/`.
- Cite the note path and its verified date. Flag notes older than 90 days or marked superseded.
- Do not read whole notes unless asked; prefer retrieved chunks.
